1. POR QUÉ NO APARECÍA NINGUNA TARJETA
--------------------------------------
- datos.js creaba dos veces "const cafeEspresso" (al principio y en la parte de las clases).
  Un const no se puede repetir: el navegador rechaza el archivo ENTERO ("Identifier 'cafeEspresso'
  has already been declared") y el arreglo productos nunca llega a existir.
  -> El segundo se llama espressoConDescuento.
- Por eso salía también "lista.forEach is not a function": sin datos.js, la palabra productos
  pasa a ser... tu <section id="productos">. El navegador crea una variable con el id de cada
  elemento, y render(productos) recibía una sección en vez de un arreglo.
